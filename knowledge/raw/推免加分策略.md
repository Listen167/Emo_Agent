附件1

广东工业大学2023年学生申请推免生论文专利

加分办法

根据有关文件规定，学生在本科阶段发表（含已录用）高水平论文或获得专利可申请推免加分，成果的第一署名单位需为广东工业大学。加分计算标准如下：

+:----:+:-------------------------------------------:+:-------------------------------------------:+:---------------------------:+:------------------------:+:--------:+:--------:+:--------:+:----------:+
| 类型 | 论 文                                                                                                                                              | 专 利                                       |
|      +---------------------------------------------+---------------------------------------------+-----------------------------+--------------------------+---------------------+----------+------------+
|      | SCI一区、二区/SSCI一区、二区/CCF推荐A类会议 | SCI三区、四区/SSCI三区、四区/CCF推荐B类会议 | EI期刊/CSSCI/CCF推荐C类会议 | ISTP/EI会议/中文核心期刊 | 发明                | 实用新型 | 外观设计/  |
|      |                                             |                                             |                             |                          |                     |          |            |
|      |                                             |                                             |                             |                          |                     |          | 软件著作权 |
|      |                                             |                                             |                             |                          +----------+----------+----------+------------+
|      |                                             |                                             |                             |                          | 授权     | 公开     | 授权     | 授权       |
+------+---------------------------------------------+---------------------------------------------+-----------------------------+--------------------------+----------+----------+----------+------------+
| 加分 | 50                                          | 40                                          | 25                          | 10                       | 40       | 10       | 10       | 5          |
|      |                                             |                                             |                             |                          |          |          |          |            |
| 标准 |                                             |                                             |                             |                          |          |          |          |            |
+------+---------------------------------------------+---------------------------------------------+-----------------------------+--------------------------+----------+----------+----------+------------+

说明：

1.根据加分计算标准，按照论文及专利的作者排位，第一排位按100%计算得分，第二排位按30%计算得分，第三排位按10%计算得分，其余不计得分。

2.同一专利技术不累计加分，只计最高分。

3.发明专利公开加分不超过两项。

确认审核单位：科学研究管理部

附件2

广东工业大学2023年学生申请推免生创新创业类竞赛

加分办法

根据有关文件规定，在学校所设定的五级创新创业竞赛中获奖的个人或团队可申请推免加分，竞赛项目参照《广东工业大学大学生竞赛级别细则》（[广工大教字〔2021〕164号](http://oa.gdut.edu.cn/xzb/admin/docpub/docs_list_a.asp)）执行。加分计算标准如下：

+:------------+:-----:+:-----:+:-----:+:------:+:-------:+
| 竞赛级别\   | 特级  | 一级  | 二级  | 三A级  | 三B级   |
| 获奖等次    |       |       |       |        |         |
|             | 竞赛  | 竞赛  | 竞赛  | 竞赛   | 竞赛    |
+-------------+-------+-------+-------+--------+---------+
| 第一等次    | 50    | 40    | 30    | 15     | 10      |
+-------------+-------+-------+-------+--------+---------+
| 第二等次    | 45    | 30    | 20    | 10     | 5       |
+-------------+-------+-------+-------+--------+---------+
| 第三等次    | 35    | 20    | 10    | 5      | 2.5     |
+-------------+-------+-------+-------+--------+---------+
| 第四等次    | 25    | 10    | 5     | 2.5    | 1       |
+-------------+-------+-------+-------+--------+---------+

说明：

1.获奖等次根据具体竞赛颁奖级别划分第一至四等次，如特等奖、一等奖、二等奖、三等奖。如果竞赛仅奖励三个等次(如金银铜奖)，则其他不算入加分。

2.团队获奖成员加分算法如下：根据加分计算标准，团队第一成员按100%计算得分，第二成员按70%计算得分，第三成员按50%计算得分，第四成员按30%计算得分，第五成员按20%计算得分,第六成员及以后按10%计算得分。

3.因同一项目多次获奖的，不累计加分，只计最高分。

确认审核单位：教务处、学生工作处、团委（由该项竞赛的牵头单位负责审核）

附件3

广东工业大学2023年学生申请推免生体育类竞赛加分办法

根据有关文件规定，在学校所设定的五级体育类竞赛项目中获奖的个人或团队可申请推免加分，竞赛项目参照《广东工业大学大学生竞赛级别细则》（[广工大教字〔2021〕164号](http://oa.gdut.edu.cn/xzb/admin/docpub/docs_list_a.asp)）执行。加分计算标准如下：

+:--------------------+:------:+:-----:+:------:+:------:+:-----:+
| 竞赛级别\           | 特级   | 一级  | 二级   | 三A级  | 三B级 |
| 获奖等次            |        |       |        |        |       |
|                     | 竞赛   | 竞赛  | 竞赛   | 竞赛   | 竞赛  |
+---------------------+--------+-------+--------+--------+-------+
| 第一等次            | 20     | 13    | 8      | 4      | 2     |
|                     |        |       |        |        |       |
| （第一名）          |        |       |        |        |       |
+---------------------+--------+-------+--------+--------+-------+
| 第二等次            | 15     | 10    | 6      | 3      | 1.5   |
|                     |        |       |        |        |       |
| （第二名---第三名） |        |       |        |        |       |
+---------------------+--------+-------+--------+--------+-------+
| 第三等次            | 10     | 6     | 3      | 2      | 1     |
|                     |        |       |        |        |       |
| （第四名---第六名） |        |       |        |        |       |
+---------------------+--------+-------+--------+--------+-------+
| 第四等次            | 5      | 3     | 2      | 1      | 0.5   |
|                     |        |       |        |        |       |
| （第七名---第八名） |        |       |        |        |       |
+---------------------+--------+-------+--------+--------+-------+

说明：1.团队获奖成员加分算法如下：团队主力队员按100%计算得分，非主力队员按50%计算得分。

2.如因同一项目多次获奖的，不累计加分，只计最高分。

3.体育类竞赛加分累计不超过40分，经体育部认定的有体育特长的学生除外。

确认审核单位：体育部
